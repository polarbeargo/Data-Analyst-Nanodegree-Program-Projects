# Data Analyst Nanodegree Projects

This repository contains three data analysis projects covering exploratory analysis, data wrangling, and communicating findings.

| Project | Question and data | Materials |
| --- | --- | --- |
| Investigate a Dataset | What movie characteristics are associated with ratings and box office revenue? Uses TMDb movie data. | [Project README](<Project Investigate a Dataset/README.md>) |
| Real World Data Wrangling with Python | How is real GDP growth associated with stock-index price changes? Combines two World Bank indicators. | [Project README](<Project Real World Data Wrangling with Python/README.md>) |
| Communicate Data Findings | How do Bay Wheels trip duration and timing vary by rider type? Uses February 2019 Ford GoBike trips. | [Project README](<Project Communicate Data Findings/README.md>) |

## Getting started

Open the notebooks in Jupyter or a compatible editor such as VS Code. For all three projects, install Python 3 and the following packages in your preferred environment:

```bash
python -m pip install jupyter numpy pandas matplotlib seaborn
```

Run each notebook from its project folder, in cell order. The wrangling notebook is in a nested folder; see its project README for the correct working directory, cached data, and refresh instructions. HTML exports are available for the movie and bike-share projects if you only want to read the reports.

Results are descriptive associations from the included datasets; they do not establish causal relationships.
